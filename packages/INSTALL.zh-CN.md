# 本地安装创作组件

这些是 **MAM0.1.42 本地未签名候选包**，没有发布到网络。`catalog.json` 记录组件目录、版本、最低宿主版本与真实清单哈希；它不代表签名或第三方信任。

1. 启动支持创作组件的 MAM0.1.42，进入创作组件库。
2. 使用本地导入，选择需要的 `creative-*` 文件夹（文件夹内含 `manifest.json`），审阅来源和能力后启用。
3. 打开已启用的组件。安装只导入组件，不自动下载模型权重，也不设置密钥。

| 用途 | 额外条件 |
|---|---|
| 图片本地预处理、写作手稿、Spine绑定/关键帧、星图编排 | 可离线操作；AI步骤另需模型 |
| 图片、视频、语音生成与写作/视觉助手 | 在 MAM 设置中配置相应创作模型；提供商可能收费 |
| 音乐、3D生成 | 在组件资源界面单独安装原始运行环境和模型，满足硬件要求 |
| ComfyUI / RIFE | ComfyUI端点在组件面板配置；RIFE程序/模型由MAM原生选择器配置；包中不含这些程序 |
| 星图本地工具 | 每次按宿主授权流程选择工作目录或批准命令 |

Windows x64 有当前原生验证证据；其他平台声明不等于 GPU流程已验证。详见 `COMPATIBILITY.md`、各组件 `provenance.json`、原项目许可证与第三方声明。安装包不含模型权重、凭据或签名。保留导出的工程备份。

重新构建全部包：使用 Node24 执行 `config/scripts/build-creative-components.mjs`。输出位于 `.mam-local/component-packages` 和 `release/creative-components/0.1.42`。
