## 当前功能基线

继承 0.1.34 的角色、版本化 Workflow、Git 权威状态、Artifact、审核、合并、诊断与 Pi RPC 续跑能力。Workflow Editor 保留循环感知布局、并行区域、返工通道、静态产物关系、固定坐标及路径追踪。Run 详情保留严格比对的产物引用匹配列表。

- Run 详情显示只读流程图，使用该 Run 冻结的 Workflow Definition 和 NodeRun 状态；可在控制路径与产物引用之间切换。节点位置沿用定义中的可选展示坐标。
- 产物引用图只绘制当前正式交付 claim 与消费 Task 固定输入引用在 Artifact ID、内容 Hash 和基础图上游关系上均匹配的边。匹配表示记录中的绑定证据，不证明执行器实际读取内容。
- 只读图不允许拖动、连接或删除节点和边；不改变 Scheduler、Run Bundle、Git 事件或 Workflow 执行计划。
