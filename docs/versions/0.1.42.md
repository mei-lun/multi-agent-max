# Multi-Agent Max 0.1.42 版本功能档案

- 状态：Windows 创作组件验收版，未完成真实模型/GPU和macOS全面验收
- 日期：2026-11-07
- 工作分支：codex/creative-components
- 基线：继承0.1.41；原MAM工作区未提交0.1.39修改保持独立

## 当前功能基线

- 八个离线可选组件：图片、视频、语音、写作、Spine、音乐、3D、星图。图片/视频/语音使用MAM适配工作台；写作、Spine、音乐、3D、星图复用锁定上游原始UI和算法，通过MAM桥接适配。
- 文字与视觉输入接通Responses、Chat Completions、Anthropic和Gemini流式协议；图片/语音沿用0.1.41，新增异步视频路由、素材上传、回执持久化与只查询恢复。
- 工程存储按组件/项目持久隔离，异步关闭先保存，拒绝或超时保留窗口；重复退出不能绕过保存。
- 音乐Python桥和3D原始launcher/worker随组件发布，运行环境与权重按需下载/离线导入；ZIP64、哈希、路径、取消/进度、备份替换与资源引用保护已接入。无运行环境时音乐SQLite历史仍可读取和导出。
- 本机GPU作业按应用数据根共享队列，音乐/3D/RIFE互斥；外部ComfyUI的实际GPU负载由外部服务管理。Windows本机尚未执行真实模型推理。
- Spine本地ComfyUI固定工作流、回执查询和RIFE主机配置接入；星图本地工具使用受限工作目录与明确命令批准。来源仓库不改动。
- 新增component_task节点与Role组件模型绑定，固定版本、权限、Claim和普通Attempt语义；Pi工具可调用明确授权组件，模型路由随快照固定，用户批准受审计，产物可作为后续调用输入。
- 新增正式asset-bundle、流式二进制CAS、授权消费/物化和可移植目录交付；未部署Git LFS自动传输。异步预验证后同步调度只检查已验证身份元数据。
- 上游快照、三方rebase、冲突阻止、新依赖声明与补丁重放可用，实际YuE2规范化变更继承验证通过。所有导入源码保持原始字节与许可。
- 开发验收启动器使用独立用户数据目录，避免覆盖日常MAM配置。
