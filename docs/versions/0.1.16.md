## 当前功能基线

继承 0.1.15 的功能基线。普通 Role Task 和 Review Task 在成功校验前不创建共享 Attempt；成功时由 `task_delivery_recorded` 原子创建正式 Attempt、保存 Effective Config、更新唯一当前交付并完成 Claim。下游开始迁移到统一 current delivery resolver。

## 本版本变更记录

### 2026-09-17 - 原子发布正式交付

- 类型：功能、修复、重构、测试
- 用户可见行为：本地失败和重试不再出现在共享 Attempt 历史；同一 Task 的第二领取者被拒绝；成功结果只产生一次正式交付。强制接管后旧 generation 不能交付。
- 实现范围：Formal Delivery 协议、Kernel authority、event application、Effective Config 写入、执行服务 Claim/Draft/Delivery 编排、current delivery resolver，以及 Artifact、Review、Merge 和 Workflow 路径迁移。
- 状态与兼容性：新增 `task_delivery_recorded` 和 `currentDeliveryAttemptId`；旧 Run 在只有一个 submitted candidate 时兼容映射，多候选时不按数组末尾猜测。
- 验证：真实 Git 执行、返工、Review、Claim 排他和 Formal Delivery 9 项通过；Pi/continuation 相关 27 项通过；resolver/Review/Merge 相关 33 项通过；typecheck、lint 与 `git diff --check` 通过。
- 已知限制：`review_aggregate`、应用重启后的完整 Draft 恢复、显式本地清理和少量 legacy-only 选择路径尚待后续版本完成；merge-conflict 系统任务暂时保留 legacy start 事件。
