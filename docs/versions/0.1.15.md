## 本版本变更记录

### 2026-09-17 - 增加本地执行草稿与模型超时策略

- 类型：功能、修复、测试
- 用户可见行为：Pi Provider 请求 timeout 自动限制在 60 至 300 秒，Provider SDK 不执行隐藏重试，Pi agent-level 最多自动重试一次；失败执行可以保留本地 Draft。
- 实现范围：Local Draft Schema/store、Pi 私有 `settings.json`、request timeout calculator、session 文件定位与 `--session` continuation 参数。
- 状态与兼容性：Local Draft 不进入 `mam-state`，不含 secret value；等待用户的时间不计入共享状态。
- 验证：Draft store、timeout、Pi launch configuration 和 Adapter 共 22 项测试通过；typecheck 和 lint 通过。
- 已知限制：应用重启后的完整 PreparedAttempt 重建和显式 Draft 清理仍需后续收口。
