## 当前功能基线

继承 0.1.18 的 Claim、Local Execution Draft、Formal Delivery 和多角色 Review Aggregate 基线，并完成恢复、权威校验和确定性边界加固。

- `needs_attention` Draft 不再进入自动恢复集合；只有用户从 Task 操作入口显式继续时才可恢复同一 Attempt。
- Local Draft 持久化不含密钥值的冻结执行上下文；重启恢复复用原 Executor Profile、本地 Executor Binding、Effective Config 与已物化资源，并校验 snapshot/hash 一致性。
- Draft 累计 active runtime；Pi 恢复时只获得剩余执行预算，provider request timeout 与整体等待 timeout 使用同一剩余上限。
- Codex、Grok 与 Pi 都消费 Draft 的剩余活动预算；Grok ACP request timeout 和 Codex process timeout 不再在恢复时重置。
- Reviewer Formal Delivery 必须原子携带 Review Decision，并校验 Review Gate、Reviewer Task、Attempt、Role Instance 与不可变 Subject 绑定。
- Delivery lineage 覆盖普通 DAG 依赖、穿过 Join 等系统节点的上游 Task、动态 Task 依赖和 Reviewer Subject；缺失、重复或过期 lineage 均被权威端拒绝。
- Review Aggregate 使用 Workflow 中固定顺序的 quorum 成员集合；权威端在 CAS 重试时重新校验当前 Subject、成员集合并重算聚合内容。
- 同机继续必须显式确认未知副作用；强制接管产生的新 Claim 不能匹配或复活旧 generation Draft。复用结果与唯一 legacy Delivery 通过统一 resolver 进入 lineage 和 Aggregate current-subject 校验。
- Review Aggregate 的 revision target 当前必须等于 producer，成员 Review Gate 必须位于 producer 到 aggregate 的同一可达路径；Aggregate 自身的 revision limit 会将超限返工转为阻塞。

## 本版本变更记录

### 2026-09-17 - 完成恢复与聚合权威边界复审修复

- 类型：修复、协议加固、测试、文档。
- 用户可见行为：模型超时后继续仍复用同一 Attempt；未知错误必须人工确认后继续；恢复不会因本地配置随后变化而静默切换执行配置；下游不能交付基于旧上游 revision 的结果；并行审核完成顺序不再改变进入总聚合的成员集合。
- 实现范围：Local Draft schema/store/restore、Attempt 执行服务与三种 Executor timeout、Workflow dependency lineage、Task Delivery authority、Review authority、Review Aggregate validation/advancement/authority，以及区分同机继续和跨机接管的桌面恢复入口。
- 状态与兼容性：版本从 0.1.18 升至 0.1.19。旧 Draft 因缺少完整冻结执行上下文会 fail closed，并要求重新准备；不迁移或共享任何 secret value。Git 权威事件保持 append-only。
- 验证：多轮复审后的 Claim/Draft/Delivery/Review/Executor 定向回归通过。使用项目要求的 Node 22 运行最终全量 Vitest，154 个文件中 151 个通过，479 项通过、1 项跳过、5 项失败；失败项仍为实施前 Windows 基线中的 2 项 POSIX `0o600` 权限断言和 3 项真实 Git merge fixture 断言。额外 Node 脚本测试 9 项通过、2 项按平台跳过；TypeScript 类型检查、lint、Electron 主进程/preload/renderer 生产构建与 `git diff --check` 通过。
- 已知限制：跨机器仍不能恢复另一机器私有的 Pi session 或 Local Draft；强制接管在新机器创建新的本地 Draft。Windows 的 POSIX mode 与真实 Git merge fixture 存在既有基线失败；macOS 发布门禁和新的两 clone acceptance evidence 尚待执行。
