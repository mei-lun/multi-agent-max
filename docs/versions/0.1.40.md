## 当前功能基线

继承已提交 0.1.38 的角色、版本化 Workflow、Git 权威状态、审核、合并、诊断、Pi RPC 续跑和流程图动效。

- 新增“创作组件”页面与八项组件目录。支持可信本地目录包导入、文件完整性检查、平台/宿主兼容检查、启停、版本占用保护和卸载；没有在线目录或发布者签名验证。
- 组件在独立 sandbox/contextIsolation 窗口加载，仅使用专用窄 IPC；主窗口 API 不对组件暴露。资产导入通过主机文件选择；任务身份绑定组件与本机项目。
- 新增持久化异步 Job、幂等、事件重放、取消/结果不明区分和人工对账接口，以及不可变二进制资产存储/验证/导出。生产生成 handler 尚未接入，组件不能凭 manifest 执行任意后端代码。
- 新增本地图片预处理组件验证包：复用 LevelUp 原始纯色背景移除算法，支持 PNG/JPEG、容差、预览、恢复原图、PNG 导出。它不包含 AI 生图或完整图片工作台。
- 新增上游已提交源码快照、来源核验、差异/依赖报告、精确补丁重放工具；所有写入限定 MAM。完整三方合并和全部功能同步尚未实现。
- 未新增 component_task、角色创作授权、正式二进制 Artifact/LFS、GPU 引擎或另外五个工作台；原任务语义不变。
