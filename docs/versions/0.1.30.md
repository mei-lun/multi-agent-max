## 当前功能基线

继承 0.1.29 的 Review 返工计数修复、显式 Review Gate 绑定、自动 Review 聚合与 merge readiness，以及 bounded revision 语义。

- 自动 Review 的非致命 `changes_requested` findings 转为 `approved` 并保留为建议，不创建返工 Attempt。
- `blocker` findings 或模型 `blocked` 仍触发有界返工/阻塞；普通 `role_task` 不会隐式审核。
- `executor_timeout` 在同一 Attempt、Draft、worktree 和 Pi session 内按角色 retry budget 自动续跑；达到预算后保留 `waiting_for_resume`。
- Attempt 页面为 timeout interruption 提供 Continue 按钮，复用同一 Draft，不创建新的正式业务 Attempt。

## 本版本变更记录

### 2026-09-20 - 将非致命 Review 转为建议并补齐 Timeout Continue

- 类型：功能、修复、测试。
- 用户可见行为：模型发现的非致命改进建议不会再触发无限返工；只有 blocker/blocked 结果进入有界返工。Executor 超时会自动续跑同一 Draft，自动重试耗尽后用户可手动 Continue。
- 实现范围：自动 Review 状态归一化、同 Draft timeout retry、Attempt 面板 Continue 操作、timeout/Review 回归测试。
- 状态与兼容性：版本从 0.1.29 升至 0.1.30；不修改共享 Workflow、Review、Attempt、Artifact 或 Git 事件 Schema。Local Execution Draft 增加可选 `continuationAttempts` 字段，缺失时按 0 恢复；既有 blocked Run 不改写。
- 验证：Node 24.19.0 下全仓 typecheck 通过；Review 计数、聚合、Human Review、分歧裁决及 publisher 26 项测试通过；自动 Review、runner、Draft 和真实 Git 恢复共 18 项通过；timeout 自动续跑真实 Git 测试通过；Attempt Continue UI 测试 2 项通过；新增 Draft continuation counter 后相关恢复测试再通过 20 项；改动文件 lint、format 和 `git diff --check` 通过。桌面 E2E 观察到 timeout Draft 保留及同 Attempt/session 恢复路径。
- 已知限制：超时后的自动续跑仍受角色 retry budget 和 Executor/provider 可用性限制；未知外部副作用仍需人工 reconciliation。当前桌面测试 Run 曾因 provider timeout 进入 `waiting_for_resume`，Continue 入口已加载在 `0.1.30` Attempt 面板。
