# Multi-Agent Max 0.1.43 版本功能档案

- 状态：Windows 创作组件候选验收版；全仓和九类本地桌面验证通过，真实厂商/GPU/macOS证据单独记录。
- 日期：2026-11-08。当前集成分支：main；来源分支：codex/creative-components。
- 基线：继承0.1.42；原MAM的0.1.39工作流连线布局与计划已单独提交保留，再与创作组件分支合并。

## 当前功能基线

- 八个离线可选组件：图片、视频、语音、写作、Spine、音乐、3D、星图。组件0.3.0，最低宿主0.1.43，后台API2.0.0。真实Provider按MAM模型配置调用，引擎资源另装。
- 每包包含实际backend.cjs及源码哈希；业务后台在独立Node进程按版本执行。MAM保留权限、凭据、资产、Job、进程监督和窗口。仅执行明确信任的本地包；进程隔离不等于恶意代码的OS沙箱。
- 新版本激活不改变旧任务使用的包；占用中旧版本不能卸载。Role同一Attempt及恢复固定版本、manifest哈希和模型。
- 手动创作按MAM项目隔离窗口、工程、素材及原生音乐数据；creative.local保留旧本机草稿入口。原生模型资源共享，项目和Attempt工作数据独立。
- 异步关闭先保存，失败保留窗口。后台Goal/星图在关闭界面后继续；Job保存检查点，重开只查询恢复，明确操作才重试。精确结果持久保存后才确认接收，防止卸载/重绘时旧状态覆盖。
- 写作Goal规划/执行/伙伴审阅、Markdown/Yarn/JSON导出及原星图执行器有后台业务API。受限UTF-8正文读取、多图候选保留、工具目录授权、真实会话历史已接通。会话绑定创作Job或当前Attempt，不增加独立Session产品。
- Spine提供工程规范化/编译、动作预设、姿态采样/拟合、图像规范化及真正ZIP导出API。Canvas在固定版本的隐藏隔离渲染器运行，保留原JSON/atlas/PNG算法；ComfyUI/RIFE使用外部安装。
- 音乐Python桥/worker及3D launcher/worker随组件发布。资源逐项原子登记，失败保留旧资源，下次安装恢复中断替换；单独rig使用Blender Python。共享GPU协调包括资源变更；取消/崩溃等待子进程树退出后才释放所有权。
- Role/component_task使用相同操作授权与逐请求批准；图/Goal内部操作也检查冻结权限/模型。零金额预算阻止潜在收费操作，允许本地/离线业务。已报告用量按Attempt累计检查，未知价格不伪造，正金额上限不等于未知计费的预付费限额。
- component.publishOutputs将Job成果转成CAS/合同与宿主交付记录，标准结果收集器支持多个二进制合同和只读Role。手动成果保存为项目/哈希固定草稿，经正常Task/Claim/Attempt提交审核。
- 成果交付UI导出/导入显式交付包，按当前项目Git清单和原生产者身份校验，恢复CAS及正式Artifact元数据；缺文件/篡改阻止下游，不伪造Task/Claim/审核。Git LFS自动分发未部署。
- 设计助手schema/materializer支持component_task、组件绑定、草稿引用和正式合同。Windows验证命令保留真实argv/退出码及.cmd支持。
- LevelUp来源只读，快照/来源映射/补丁/三方合并/冲突报告保留。真实UI和纯函数修复继承已演练；原生协议变化列人工适配清单，不承诺自动语义转换。
- Ed25519离线catalog签名/验证及原子导入接口可用，公钥由操作者独立信任；没有伪造官方密钥或线上发布。证据绑定源码指纹、基线提交、平台、运行时及包manifest哈希。
