## 当前功能基线

本版本继承 `0.1.0` 的所有仍受支持能力，包括 Git 驱动的 Workflow Run 状态、角色与资源 Profile、独立 Attempt worktree、审查与合并队列、工作流包、设计助手、执行观测和本机配置。完整的冻结历史基线见 [`0.1.0.md`](0.1.0.md)。

- Git 状态继续由 `mam-state` 分支持久化；有 remote 时默认使用分布式协作。
- 每个可执行工作流节点固定其 Role Profile；Scheduler Kernel 独占权威状态和受控 Git 操作。
- 角色本机绑定、密钥、Skills、MCP 和知识库绑定保留在本机，不写入 Git 状态。
- macOS 仍是发布门禁；Windows 仅支持开发环境引导，Linux 尚未纳入发布范围。

## 本版本变更记录

### 2026-09-03 - 增加纯本地 Git 执行模式

- 类型：功能、配置、测试
- 用户可见行为：设置中可启用 `Local-only execution`。即使项目配置了 Git remote，MAM 也只创建和更新本地 `mam-state` 与任务分支，不会探测、拉取或推送远端 Git 状态。
- 实现范围：`src/shared/mam/local-settings.ts`、`src/main/index.ts`、`src/main/mam/state-store/git-state-repository.ts`、`src/renderer/src/features/mam/MamLocalSettingsEditor.tsx`、相关真实 Git 测试和 UI 测试。
- 状态与兼容性：新增本机 `collaborationMode` 设置，缺失时按 `distributed` 解析；事件格式、状态分支名称和本地 CAS 语义保持不变。更改设置后须重新选择项目或重启应用以重新连接仓库。
- 验证：`corepack pnpm typecheck`、`corepack pnpm lint`、Git state repository 集成测试和相关 UI 测试通过。
- 已知限制：当前已连接的 Repository 实例不支持保存设置后的 remote 热切换。

### 2026-09-03 - 强制代码变更递增 patch 版本

- 类型：配置、文档
- 用户可见行为：每次独立的运行时代码行为变更都会获得新的 patch 版本和对应版本档案，避免多个变更共用同一个版本号。
- 实现范围：`AGENTS.md`、`docs/versions/README.md`、`package.json` 和本档案。
- 状态与兼容性：版本从 `0.1.0` 升至 `0.1.1`；无运行时 schema 或迁移影响。
- 验证：人工核对 `package.json`、版本索引和档案名称一致。
- 已知限制：纯文档变更仍只要求更新当前版本档案，不强制发布新的软件版本。
