## 当前功能基线

本版本继承 `0.1.12` 的所有仍受支持能力，包括 Git 驱动的 Workflow Run 状态、固定角色工作流、独立 Attempt worktree、审核与合并队列、设计助手、执行观测、纯本地或分布式 Git 协作以及本机 Profile 和资源绑定。

- Git 状态由 `mam-state` 分支持久化；Scheduler Kernel 独占权威状态和受控 Git 操作。角色不共享聊天上下文，正式输入输出通过已校验 Artifact 和 Git commit 交接。
- 每个可执行节点固定一个 Role Profile；Role 显式绑定 Skill、MCP 和知识库，不继承全局 Executor 资源。
- 角色到角色的文件交接必须经过 Workflow 中显式的 Review 与 `git_merge`；下游按 Git ancestry 固定到已完成集成节点的唯一终端 merge commit。
- Review 绑定当前选中的不可变已提交 Attempt；过期自动 Review 记为 superseded，不参与聚合，也不触发 Attempt 失败恢复。
- Review 聚合由应用发布和 Scheduler authority 共用同一个确定性计算器；决策和 finding 按稳定键规范化，完成顺序不改变聚合结果。
- Review 返工上限沿 `previousAttemptId` lineage 只统计已提交的正式前序 Attempt；Provider timeout、blocked 和 `needs_reconciliation` Attempt 不再消耗返工次数。
- 设计助手请求属于当前设计草稿生命周期；切换页面时生成继续运行，只有显式停止或确认放弃时才取消。
- 当前生产 Attempt 只使用 Pi RPC；Codex CLI 与 Grok CLI Adapter 尚未启用。
- 本地桌面日志、业务诊断和 Pi RPC 日志按记录时间滚动保留 24 小时；日志目录可配置并于重启后生效。
- macOS 仍是发布门禁；Windows 支持开发验证，Linux 尚未纳入发布范围。

## 本版本变更记录

### 2026-09-17 - 统一 Review 聚合与正式返工计数

- 类型：修复、重构、测试、文档
- 用户可见行为：包含 Provider 超时或失败恢复 Attempt 的任务在收到 `changes_requested` 时，不再因历史 Attempt 总数错误进入 `blocked`；应用发布器和 Scheduler Kernel 不再对同一组 Review 计算出不同状态，因此避免 `Review aggregation is not deterministic` 中断。
- 实现范围：新增共享 `review-aggregation-calculator` 与 `review-revision-counter`；Review publisher、Scheduler authority 和人工分歧处理统一使用正式 lineage 计数；补充顺序确定性、revision 上限、timeout-only lineage 和实际故障边界测试；更新产品权威、中文设计规格和分版本实施计划。
- 状态与兼容性：版本从 0.1.12 升至 0.1.13；不新增持久化事件或 Schema。现有旧 Run 可按已提交 Attempt lineage 重新计算聚合。产品权威已切换到 Task Claim、Local Execution Draft 和 Formal Delivery 的目标语义，但这些协议改动将在后续 patch 版本实现。
- 验证：Review、Scheduler 与聚合相关 13 个测试文件共 34 项通过；TypeScript 类型检查通过；新增测试覆盖决策乱序、finding 去重、revision 上限、两个 timeout-only Attempt 后的正式交付和 Kernel canonical 校验。全量基线在改动前为 443 项通过、1 项跳过、5 项既有 Windows 失败。
- 已知限制：本版本尚未实现排他 Task Claim、Local Execution Draft、Pi session 继续、Formal Delivery 或 `review_aggregate`；普通 Provider timeout 仍会进入旧 Attempt recovery 路径。macOS 发布门禁尚未在本机执行。
