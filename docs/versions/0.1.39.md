# Multi-Agent Max 0.1.39 版本功能档案

- 状态：开发中
- 版本日期：2026-10-30
- 发布门禁：macOS
- 当前生产 Executor：Pi RPC
- 产品权威：[`final-reuse-integration-plan.md`](../final-reuse-integration-plan.md)、[`MAM_REQUIREMENTS_DELTA_2026-07-27.md`](../readme/MAM_REQUIREMENTS_DELTA_2026-07-27.md)

## 当前功能基线

继承 0.1.38 的角色、版本化 Workflow、Git 权威状态、Artifact、审核、合并、诊断、Pi RPC 续跑，以及工作流列表、编辑器和 Run 记录中的流程图。静态定义关系与运行记录中的产物引用证据保持明确区分。

- 工作流列表、编辑器和 Run 只读图可切换控制路径与产物关系/引用，并保留 0.1.38 的可暂停方向动效与 reduced-motion/可见性处理。动效仅表示关系方向，不表示实时数据传输或执行进度。
- 自动排版为节点间的边标签保留更宽的水平间距；控制与产物标签优先选择空闲节点间隙，按可用宽度换行，并避开节点和已有标签。手工固定节点位置继续生效。
- 有界返工边沿现有外围通道显示；Workflow Definition、Run、Artifact、事件与执行计划的数据结构未改变。

## 本版本变更记录

### 2026-10-30 — 修复流程图中间节点与关系标签重叠

- 类型：修复、优化、测试。
- 用户可见行为：产物关系与控制路径中的长标签不再盖住中间方框，多个标签会避让；自动排列的节点间距更充足。
- 实现范围：共用布局列间距、编辑器/列表预览/Run 的标签定位、边标签换行宽度与定向回归测试。
- 状态与兼容性：从 0.1.38 升至 0.1.39；无 Workflow、Run、Artifact、事件或 UI Schema 迁移，旧定义及固定位置保持有效。
- 验证：定向 Vitest、TypeScript、oxlint、格式检查、生产构建与桌面烟雾验证。
- 已知限制：用户手工固定节点可形成极密图；当前按节点矩形与估算文字宽度避让，不提供密集图全局最优路由。macOS 实机视觉验收待发布门禁完成。
