## 当前功能基线

本版本继承 `0.1.10` 的所有仍受支持能力，包括 Git 驱动的 Workflow Run 状态、固定角色工作流、独立 Attempt worktree、审核与合并队列、设计助手、执行观测、纯本地或分布式 Git 协作以及本机 Profile 和资源绑定。

- Git 状态继续由 `mam-state` 分支持久化；Scheduler Kernel 独占权威状态和受控 Git 操作。角色不共享聊天上下文，正式输入输出通过已校验 Artifact 和 Git commit 交接。
- 角色到角色的文件交接必须经过 Workflow 中显式的 Review 与 `git_merge`。下游 Attempt 按 Git ancestry 固定到已完成集成节点的唯一终端 merge commit，并收到包含 Artifact 类型、路径或 glob、hash、生产节点、Attempt 与来源 commit 的输入清单；未集成或多集成基线歧义时拒绝启动。同一动态节点内无法表达独立 Review/merge 的兄弟 Task 文件 Artifact 交接会在 Task Plan 物化前被拒绝。
- 每个可执行节点固定一个 Role Profile；Role 显式绑定 Skill、MCP 和知识库，不继承全局 Executor 资源。
- 桌面自动协作由 Renderer 的本机协作协调器按 `automaticWorkflowRunIds` 推进；同一应用进程对相同项目、Run 和 Task 的重叠启动请求会合并，跨 clone 的合法并发 Attempt 继续保留并显示 warning。
- Review 绑定当前选中的不可变已提交 Attempt；过期自动 Review 记为 superseded，不写入 Review 决策、不参与聚合，也不触发 Attempt 失败恢复。
- 当前生产 Attempt 只使用 Pi RPC；Codex CLI 与 Grok CLI Adapter 尚未启用。
- Resources 支持从本地 Codex 用户、内置、已启用插件和 `config.toml` 来源选择导入 Skill 与 MCP；角色本机绑定、密钥、健康结果和导入事务状态只保存在本机。
- 本地桌面日志、业务诊断和 Pi RPC 日志按记录时间滚动保留 24 小时；日志目录可在设置中修改并于重启后生效。
- macOS 仍是发布门禁；Windows 支持开发验证，Linux 尚未纳入发布范围。

## 本版本变更记录

### 2026-09-16 - 修复角色间 Artifact 与 Git 基线交接

- 类型：修复、功能、测试、文档
- 用户可见行为：后续角色不再从仓库任意 `HEAD` 启动。若其输入来自上游角色，工作流必须先完成 Review 和配置目标分支的 `git_merge`；下游从 Git ancestry 确认的唯一终端合并 commit 创建独立 Attempt，并在 Prompt 中获得可追溯输入清单。设计助手会明确要求并校验这一工作流结构，动态兄弟任务的无集成交接会被明确拒绝。
- 实现范围：新增 Attempt handoff 解析与集成基线选择；扩展 Attempt worktree 对目标分支的按需 fetch；执行 Prompt 注入 Artifact 来源、位置、hash 与 commit；新增设计助手交接规则及提案校验；同步产品权威文档。
- 状态与兼容性：版本从 0.1.10 升至 0.1.11；不新增事件或状态 Schema，不需要迁移 `mam-state`。既有已冻结 Run 保持定义不变，但仍绕过集成节点的角色文件交接会在新 Attempt 启动时被拒绝，需要创建修正后的 Workflow 新版本。
- 验证：10 个持久专项文件 49 项测试通过；另以临时测试通过主项目 Schema、Workflow 编译器和设计校验器验证两个外部模板，合计 11 个文件 51 项通过。typecheck、全仓 lint、核心构建和 Electron 桌面构建通过。Node 24.19.0 下全仓 135 个测试文件、434 项通过、1 项跳过；剩余 5 项为既有 Windows 基线失败，包括 2 项 POSIX `0o600` 权限断言和 3 项真实 Git merge fixture 断言。完整 format:check 仍受仓库既有 432 个 CRLF/格式基线文件影响，本次修改文件单独检查通过。
- 已知限制：入口外部 Artifact 仍沿用现有引用机制；本次只修复 Workflow 内静态 Role-to-Role 文件交接。并行分支汇聚到多个不同集成基线时必须先通过 Workflow 收敛为唯一 `git_merge`，系统不会猜测合并顺序；动态兄弟 Task 的文件交接暂不支持。
