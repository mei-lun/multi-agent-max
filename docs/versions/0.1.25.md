## 当前功能基线

继承 0.1.24 的 Provider 地址归一化、Responses 流式传输、推理强度配置、模型目录发现、协议分流、Review 工作流和 Design Assistant 诊断。

- Design Assistant 的 90 秒 Provider 时限只约束响应头；收到响应头后的流式正文可以继续读取至正常完成。
- 用户取消、重置草稿、过期 Draft 和超大响应仍沿用既有拒绝行为。
- OpenAI Responses/Compatible 模型支持可配置推理强度；Responses 请求默认使用 `medium`。

## 本版本变更记录

### 2026-09-20 - 恢复 Design Assistant 长响应读取

- 类型：修复、测试。
- 用户可见行为：中转在 90 秒内返回响应头后，Design Assistant 不再因完整生成超过 90 秒而丢弃已经开始返回的成功结果。
- 实现范围：仅调整 Design Model Gateway 的响应头计时器生命周期，并增加延迟 SSE 正文回归测试。
- 状态与兼容性：版本从 0.1.24 升至 0.1.25；无 Schema、Profile、草稿或迁移变化。
- 验证：Design Model Gateway 定向测试、Provider/Design/Pi 相关测试、TypeScript 类型检查、lint、格式检查和桌面构建。
- 已知限制：响应头到达后不施加固定总时限；用户仍可通过现有停止操作取消生成。
