## 当前功能基线

继承 0.1.35 仍受支持的角色、版本化 Workflow、Git 权威状态、Artifact、审核、合并、诊断、Pi RPC 续跑，以及编辑器与 Run 详情中的流程图。控制图保留基础 DAG、并行区域、有界返工标签；产物视图分别呈现定义阶段候选关系和 Run 详情中可核对的当前产物引用。

- 有界返工边从节点顶部端口出发后进入源列外侧走廊，再在节点上方的独立通道横穿，最后从目标列外侧走廊返回目标顶部。通道根据图中节点位置与重叠边稳定分配，减少同列堆叠节点遮挡回线。
- 图路由仍属于只读展示逻辑；节点、Workflow Definition、执行计划、Git 权威事件和 Scheduler 状态转换保持既有语义。
