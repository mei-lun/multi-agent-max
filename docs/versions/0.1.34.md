## 当前功能基线

继承 0.1.33 仍受支持的角色、工作流、Git 权威状态、Artifact、审核、合并、诊断以及 Pi RPC 续跑能力。工作流定义仍是带版本的执行图；Run 固定定义版本，执行节点继续沿用固定角色。

- Workflow Editor 保留 0.1.33 的基础 DAG 布局、并行区域、静态产物数据视图、节点查找与固定坐标；有界返工线使用根据节点位置求出的独立上方通道，尽量避开跨越区域内的节点，并分开重叠的回路线。
- Run 记录新增只读的“运行产物绑定”列表。它使用 Run 冻结定义、节点运行身份、当前正式交付的 Artifact claim 和消费 Task 固定输入引用，只有 Artifact ID 与内容 Hash 都匹配且生产节点位于消费节点上游时才显示“引用匹配”；否则标明多来源或外部/未识别来源。该列表不声称执行器实际读取了产物。
- UI 快照可选提供冻结 Workflow Definition、Task 的 nodeId 和当前正式交付 Attempt ID，供前端解释既有权威状态；不新建调度事件，不修改 Run Bundle 或 Scheduler 语义。
- 无 0.1.34 可选 UI 字段的旧快照仍可解析；只读渲染不会反向修改 Workflow Definition。旧版应用的 UI Schema 不接受新增字段，跨版本桌面客户端仍应同步升级。
