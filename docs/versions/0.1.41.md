# Multi-Agent Max 0.1.41 版本功能档案

- 状态：开发中，图片与语音工作台接入
- 版本日期：2026-11-07
- 基线：继承 0.1.40 的创作组件基础与已提交 0.1.38 应用功能；原工作区未提交 0.1.39 变更未混入
- 产品权威：`docs/final-reuse-integration-plan.md` 与 `docs/creative-components-authority.md`

## 当前功能基线

- 保留组件本地安装/启停/版本租约、只读上游同步、Job/资产存储和隔离窗口。
- 图片组件 0.2.0 提供模型选择、批量提示、参考图排序、蒙版绘制/恢复/扩边/撤销、历史搜索/分页、参数复用、重试、取消、预览、导出和本地背景处理。
- 新增语音组件 0.1.0，提供文字、模型/音色/格式、后台任务、音频播放、历史复用、导出和删除。
- 主进程通过 MAM 加密凭据存储调用支持的图片与语音协议；组件页面只获取无密钥模型目录。支持范围和测试证据见媒体接入验收，不把本地 HTTP 模拟当作实际厂商在线验收。
- 图片结果通过实际解码验证，返回 URL 使用独立公网 HTTPS 下载且不携带模型密钥；资产文件名按实际 MIME。批量请求固定配置，每次请求一张、有限并发，保留部分成果和失败状态。
- 组件素材导入只读取一个有界快照，预览按窗口授权，导出使用系统确认和同目录临时文件替换，阻止覆盖 MAM 管理目录。删除历史先保留输出资产授权。
- 新保存的已识别图片/语音连接不再声明文字工具调用能力。
- 尚未完成视频、写作、Spine 完整编辑器、音乐、3D、星图、角色创作授权、component_task、正式 Artifact/LFS 和在线签名分发。

## 本版本变更记录

### 2026-11-07 — 接通图片与语音的实际宿主路径

- 类型：功能、测试、修复、文档。
- 用户可见行为：安装组件后可使用 MAM 已配置的支持模型生成/编辑图片及合成语音；结果进入本机历史，可预览并导出。没有兼容模型时明确提示配置。
- 实现范围：媒体协议适配与来源映射、加密密钥接线、组件素材/模型接口、图片/语音界面与构建器、原生 QA；仅修改 MAM worktree。
- 状态与兼容性：新增组件版本与操作，不改变既有 Workflow/Attempt/Artifact schema。旧本机 Job 保留；模型选择在提交时固定，迟到蒙版/界面操作被拒绝。
- 验证：TypeScript、lint、媒体 HTTP/授权/文件回归；真实 Electron 经实际生产桥接完成模型配置、生成/参考编辑、后台关闭重开、幂等、图片预览、原字节导出、语音 WAV 播放/导出；图片 UI 异步竞态与 720px 浅深色验证。
- 已知限制：未调用付费厂商或 GPU；线上模型兼容和美术质量仍需实测。音视频引擎及正式流程交付仍在后续计划中；全仓已有六项 Windows 基线失败记录保留。
