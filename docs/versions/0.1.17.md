## 当前功能基线

继承 0.1.16 的功能基线，并允许多个固定不同 Reviewer Role 的 Review Gate 审核同一 Formal Delivery，再由无 Role 的 `review_aggregate` 系统节点按成员、quorum 和稳定顺序汇总结论。

## 本版本变更记录

### 2026-09-17 - 增加多角色 Review Aggregate

- 类型：功能、重构、测试、文档
- 用户可见行为：Workflow 可以配置多个不同审核角色并行审核同一交付；聚合结果不受各审核完成顺序影响，混合结论进入人工分歧处理。
- 实现范围：`review_aggregate` Workflow Schema、拓扑校验、编辑器节点与字段、跨 Gate 聚合计算、Scheduler 命令/事件与 authority、确定性节点推进。
- 状态与兼容性：新增 `record_review_aggregate` 与 `review_aggregate_recorded`；普通 `review_gate` 行为保持兼容。
- 验证：Review Aggregate、Workflow Compiler 和 Canvas model 共 10 项测试通过；typecheck 与 lint 通过。
- 已知限制：Design Assistant 自动生成多审核拓扑的 prompt 优化和完整桌面 E2E 仍需最终收口；应用重启后的 Local Draft 完整恢复仍是已知限制。
