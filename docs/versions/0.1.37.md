## 当前功能基线

继承 0.1.36 仍受支持的角色、版本化 Workflow、Git 权威状态、Artifact、审核、合并、诊断、Pi RPC 续跑，以及编辑器和 Run 记录中的流程图。工作流图按基础 DAG、并行区域、条件和有界返工展示，定义层产物关系与运行时引用匹配保持明确区分。

- 工作流列表中的**已有活动 Workflow Definition**直接显示只读流程图，并可切换控制路径与定义阶段的产物关系。没有 `presentation` 展示字段的旧定义由现有确定性布局算法排版，无需创建新工作流，也无需保存一个新版本。
- “编辑新版本”继续打开可编辑的 XYFlow 画布；列表预览不修改原定义、执行计划、Git 权威事件或已有 Run。运行记录仍使用冻结的 Run 定义呈现只读图。
