## 当前功能基线

继承 0.1.31 的 Review 建议化、同 Draft 超时恢复、进程重启恢复和手动 Continue，以及仍受支持的角色、工作流、Git 状态、Artifact、审核、合并和诊断能力。

- Pi RPC 将可识别的超时、连接中断、限流和临时服务错误归为可重试连接故障；在冻结的 Role retry 上限内继续同一 Draft、Attempt ID、配置、Pi session 和 worktree。
- 自动重试耗尽后，本机持有有效 Task Claim 的用户在“待我处理”看到连接中断事项、次数和依赖影响；明确点击重试后继续原 Draft。没有可用 Pi session、worktree 或剩余运行预算时，说明原因并禁用直接重试。
- 本机待处理事项不写入 `mam-state`，其他机器不能操作；保留正式 Attempt 的不可变交付边界。
- 自动协作在一个 Task 等待重试、人工决定或仍在执行时继续查找其他已就绪、无依赖的 Task。
- 没有明确连接故障证据、会话安全性无法确认或外部非幂等副作用未知时，仍使用恢复核对流程；不自动切换 Executor、Provider 或 Model。
