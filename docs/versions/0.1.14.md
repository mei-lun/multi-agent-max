## 当前功能基线

继承 0.1.13 的功能基线，并增加 Task 级排他 Claim：一个 Task 最多一个 active Claim；普通重复领取被拒绝；用户可以填写原因强制接管；generation fencing 拒绝过期领取者。Claim 不改变 Workflow 固定 Role，也不恢复 Device Registry 或 heartbeat。

## 本版本变更记录

### 2026-09-17 - 增加排他 Task Claim

- 类型：功能、重构、测试、文档
- 用户可见行为：Task 可以领取、释放和强制接管；已有领取时不再允许第二个普通执行者并发启动。
- 实现范围：Task Claim Schema、Scheduler 命令/事件与 authority、Git projection/replay、Application API、IPC/preload、Task snapshot 和强制接管 UI。
- 状态与兼容性：新增 `task_claimed`、`task_claim_released`、`task_claim_taken_over`；legacy Attempt 事件继续可重放。
- 验证：Claim authority、event application、Application command 与 Kernel 定向测试通过；typecheck 和 lint 通过。
- 已知限制：本版本尚未把 Provider timeout 留在本地 Draft，也尚未通过 Formal Delivery 完全删除交付前 Attempt。
