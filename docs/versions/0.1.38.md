## 当前功能基线

继承 0.1.37 的角色、版本化 Workflow、Git 权威状态、Artifact、审核、合并、诊断、Pi RPC 续跑，以及编辑器、已有工作流列表和 Run 记录中的流程图。静态定义关系与运行记录中的产物引用证据保持明确区分。

- 工作流列表、编辑器和 Run 只读图增加可切换的方向动效。控制边与有界返工边沿实际路径显示光迹与移动光点；产物关系边在光迹之外显示沿源节点到目标节点移动的数据包。静态箭头与标签一直保留，关闭动效后图的意义不变。
- 可见画布默认播放，用户可点击“暂停动效”停止并再次播放；窗口隐藏及系统 `prefers-reduced-motion: reduce` 时不创建动效。控制与产物视图只播放当前可见关系。
- 动效只演示定义和引用关系的方向，不表示真实数据传输、Agent 内容读取或执行进度；不进入 Workflow Definition、Run、事件、导出或执行计划。

## 本版本变更记录

### 2026-10-30 — 为流程图增加可控方向动效

- 类型：功能、优化、测试、文档。
- 用户可见行为：用户可以在已有工作流、工作流编辑器和 Run 流程图中播放/暂停流向动效，控制边与产物边的效果不同；减少动态效果设置下保持静态图。
- 实现范围：XYFlow 定制连线和返工路径光迹、产物数据包、动效开关及 reduced-motion/可见性处理、桌面烟雾探测、定向渲染测试。借鉴 Archify Viewer 的方向光迹、数据包与暂停语义。
- 状态与兼容性：从 0.1.37 升至 0.1.38；没有新增 Workflow、Run、Artifact、事件或 UI Schema，也不改变 `planHash`，旧定义和旧 Run 无需迁移。
- 验证：定向 Vitest 4 个文件、12 项通过；TypeScript、oxlint、核心与桌面生产构建、seeded desktop smoke 通过；桌面截图确认旧工作流列表中出现沿路径移动的光点和暂停控件。`git diff --check` 检查变更格式。全仓既有 Windows 文件权限与 Git 合并用例失败仍按 0.1.33 基线记录，本次未修改这些模块。
