## 运行与限制

使用仓库要求的 Node 22.22+ 和 pnpm 10.24.0。当前机器全局 Node 为 20，因此本批通过 Codex 自带 Node 24.19.0 运行检查，未改变全局环境。

图片组件输出：`.mam-local/component-packages/creative-image/`。在本分支构建的 MAM 中打开“创作组件”，导入该目录并启用，即可使用本地图片预处理。其他目录项目前只是可选组件的预留位置，不是可用生成实现。

MAM 生产后端 handler 目录当前为空；桥接会明确拒绝未接入操作。没有真实 AI 生图/视频/语音、写作、音乐、Spine 编辑器或 3D 推理验收。没有发布网络安装目录、签名包或安装器，也没有合并到原 main。

后台服务对用户数据根加排他所有权锁；进程异常退出留下的失效锁目前保守阻止启动并要求确认旧进程退出后恢复，自动失效锁恢复仍需后续完善。
